## Preparación y limpieza

SETUP (POST /__demo/prepare) reinicia exclusivamente los datos sintéticos y emite sesiones nuevas para ambos usuarios. CLEANUP elimina el pedido creado, verifica GET 404 y listado inicial de 3; elimina variables sensibles. Aunque una aserción falle, el runner continúa hasta CLEANUP. Un fallo de transporte o interrupción puede impedir limpieza: repetir desde SETUP, sin reutilizar IDs.
